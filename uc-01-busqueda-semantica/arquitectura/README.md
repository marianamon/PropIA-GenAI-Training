# Arquitectura — UC-01

Esta carpeta es el espacio para tus diagramas de arquitectura específicos del UC mientras lo implementas (componentes internos, decisiones de diseño, etc.).

El **diagrama de secuencia oficial** del UC vive en [`docs/diagrams/uc-01-secuencia.md`](../../docs/diagrams/uc-01-secuencia.md) — léelo antes de empezar a codificar.

## Qué agregar aquí

- `componentes.md` — diagrama Mermaid de los componentes que estás construyendo (`search.ts`, `api.ts`, etc.) y sus dependencias con `@propia/*`.
- `decisiones.md` — ADRs (Architecture Decision Records) breves: por qué elegiste un valor de `k`, por qué L2 vs cosine, etc.
