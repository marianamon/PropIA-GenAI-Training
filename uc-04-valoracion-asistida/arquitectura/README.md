# Arquitectura — UC-04

Esta carpeta es el espacio para tus diagramas de arquitectura específicos del UC mientras lo implementas (componentes internos, decisiones de diseño, etc.).

El **diagrama de secuencia oficial** del UC vive en [`docs/diagrams/uc-04-secuencia.md`](../../docs/diagrams/uc-04-secuencia.md) — léelo antes de empezar a codificar.

## Qué agregar aquí

- `componentes.md` — diagrama Mermaid de los módulos que construyes y cómo se conectan con `@propia/*` (shared, embeddings, db).
- `decisiones.md` — ADRs (Architecture Decision Records) breves: configuración del modelo elegido, tradeoffs de chunking/temperatura/etc.
